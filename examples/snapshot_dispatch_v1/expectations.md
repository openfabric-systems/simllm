# Primitive snapshot dispatch qualification

This prospective CORE-68 study qualifies host work in the complete typed snapshot visitor. It does not qualify independent native engine completion. The source before the change is `f904b29a3d25c2ae0a955cb1d771f6148f3ceb2b`. Only `simllm/core/value_snapshot.py` may differ in the installed package. The old fallback remains byte-for-byte present, with an identity-only prefix for exact strings, integers, booleans, bytes, None and finite floats. Every reached input still produces a fresh tuple. Floats retain finite rejection and hexadecimal encoding. No cache, history truncation, removed guard or container fast path is permitted.

## Mechanism and bounds

The visitor reads each input once. Let h be the number of tuple rows in an outer list and q the repetitions per row of the ordered primitive vector (Unicode string, large integer, boolean, bytes, None, negative zero). The sweep is h in {1, 4, 16}, q in {1, 4, 16}, plus an empty-list control. Primitive visits S = 6hq, container visits C = h + 1 and all visits N = 1 + h + 6hq. These are per occurrence, including repeated aliases.

The physical work floor is N input visits and N output nodes on both sources. The work ceiling is the original dispatch path. Direct calls from `visit` to `isinstance` are S + 3C before and 3C after. Their difference is exactly S. Calls to `is_dataclass` remain C, and calls to `isfinite` and `float.hex` remain hq. The empty-list case has exactly zero reduction and is an unscored fatal compatibility guard. The nine nonempty cases form one behavioral family. Binary profiles are retained and reread in full; recursive call totals and caller attribution are used, not primitive invocation counts or profile-wide builtin totals. Wall time is diagnostic only and has no speedup acceptance claim.

Actual sink publication readers repeat the existing publication snapshot h/q sweep, with complete typed inputs, snapshots, prepared records and simulations retained. Process-local object IDs are retained and checked against their declared identity slots; only those slots are projected to fixed labels for cross-process comparison. The input and output node counts, every non-identity value and reader invocation count are identical across sources. These are compatibility guards, not extra behavioral points.

Six actual local decode jobs reuse the locked `publication_snapshot_v1` configuration and helpers: layer count 1 or 2 and prior-step history 0, 1 or 4. All ten publication collections, records, simulations, completion events, queue visits, results, service values and completion times are retained and source-paired exactly. Guard invocation counts are retained in full profiles and compared. The per-layer weight-read floor is 16,384 bytes divided by 8 TB/s, or 2,048 ps. The conservative per-layer ceiling is 1,000,000,000 ps. More layers must increase service, bounded by twice one-layer service plus 1,000 ps. Histories add exactly one unchanged service per step. These tiny ideal-host jobs qualify compatibility only, with no plausible full-model or measured GPU latency claim.

## Finite semantic contract

The named matrix in `expectations.json` covers typed primitives, signed zero and nonfinite floats; primitive subclasses; integer and string enums; Fraction and path subclasses; dynamic type metadata; equality/hash-spoofing metaclasses; dataclass instances and classes, including a field excluded from equality; repeated aliases, ordered dictionary keys and values, sets, cycles; successful, declined, nested, raising and cyclic projections; and reversed competing failures. The complete result or exception type/message and declared hook trace are compared with the frozen original implementation using freshly reconstructed fixtures. Opaque values admitted by a spoofing metaclass carry an explicit identity witness, never equality-based comparison. Fresh tuple identity is checked explicitly.

Fraction virtual registration before traversal and registration inside a projection run in separate fresh processes for each source. Both preserve the original fallback behavior, including its missing-numerator error for a virtually registered list. Container dispatch shortcuts are forbidden. Traceback locations, resource/recursion thresholds, source monkeypatching and introspective callbacks are outside this finite compatibility contract.

All 14 existing deferred mutation cases and six reader-binding cases run on both sources. Full pre-trigger and post-trigger fixtures, ordered exceptions, poisoned state and rejected retry are retained and independently reconstructed using the locked helper checker. No deleted check may be excused by final output equality.

## Admission and closure boundary

Six fresh processes run: before/after main captures and two isolated virtual-registration captures per source. Each has a 600-second wall limit, 8 GiB resident-memory limit and 0.25-second sampling. No model weights, native framework, GPU allocation or packet backend runs are involved. Capture every first process-exit receipt before admission, including on startup failure, nonzero exit or timeout. Source, helper, interpreter, profile, raw-file and receipt continuity are fatal.

Admission rejects altered source receipts, altered profile calls, omitted semantics, changed model results, missing mutation fixtures and disk-only byte changes. Controls are unscored. Any failed guard or incomplete process voids the run and leaves a null behavioral score. Exact oracles are the ten primitive snapshot/count vectors and six complete source-paired job vectors, counted once per pair. Behavioral evidence is nine instances in one family. Structural guards, the semantic matrix, actual-reader compatibility and negative controls are separate and unscored.

A passing study establishes less dispatch work with complete reads and unchanged declared behavior. CORE-68 remains open until the original native workload completes within its original limits. Earlier void evidence remains immutable, and this study cannot be used to rescore it. CORE-52, CORE-70 and the deployment frontier are outside this closure.
